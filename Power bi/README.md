# Введение

Этот дашборд был создан для **соискателей**, **специалистов, планирующих смену карьеры**, и **тех, кто рассматривает смену работы**, чтобы решить распространённую проблему: информация о рынке вакансий в сфере данных разрознена и её сложно быстро понять.  
Используя **реальный датасет вакансий в области Data Science за 2024 год** (включая должности, зарплаты и локации), проект предоставляет единый, удобный интерфейс для анализа рыночных трендов и уровня компенсаций.

# Продемонстрированные навыки

Этот проект стал практическим путешествием по ключевым возможностям **Power BI**. Ниже перечислены навыки и инструменты, которые были освоены:

### ⚙️ Трансформация данных (ETL) с Power Query
Очистка, преобразование и подготовка исходных данных к анализу: работа с пропущенными значениями, изменение типов данных и создание новых колонок.

### 🧮 Неявные меры (Implicit Measures)
Создание мер для получения ключевых инсайтов и KPI, таких как **медианная годовая зарплата** и **количество вакансий**.

### 📊 Основные типы визуализаций
Использование **столбчатых**, **линейных** и **площадных графиков** для сравнения количества вакансий и отслеживания трендов во времени.

### 🗺️ Геопространственный анализ
Применение **карт** для визуализации глобального распределения вакансий.

### 🔢 KPI-индикаторы и таблицы
Использование **карточек (Cards)** для отображения ключевых метрик и **таблиц** для детального и сортируемого представления данных.

### 🎨 Дизайн дашборда
Проектирование интуитивно понятного и визуально привлекательного интерфейса, использование как популярных, так и менее распространённых типов визуализаций для лучшего раскрытия истории данных.

### 🖱️ Интерактивная аналитика
- **Слайсеры (Slicers):** динамическая фильтрация отчёта по должностям  
- **Кнопки и закладки (Buttons & Bookmarks):** создание удобной навигации  
- **Drill-Through:** переход от общего обзора к детальному, контекстному анализу
