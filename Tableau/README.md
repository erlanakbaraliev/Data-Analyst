# Airbnb Listings 2016 – Tableau Dashboard

This project contains a simple **Tableau dashboard** built using the Airbnb Listings 2016 dataset.

Dataset:
[https://www.kaggle.com/datasets/alexanderfreberg/airbnb-listings-2016-dataset](https://www.kaggle.com/datasets/alexanderfreberg/airbnb-listings-2016-dataset)

## Overview

The dashboard explores Airbnb prices based on **bedrooms, location, and time**.

Visualizations included:

* **Average Price by Bedrooms** – Shows how listing prices increase with the number of bedrooms.
* **Average Price by Zip Code** – Compares prices across different areas.
* **Price Map** – Geographic view of average prices by location.
* **Monthly Price Trend** – Displays how Airbnb prices change throughout the year.

## Tools

* Tableau Public
* Airbnb Listings 2016 dataset
